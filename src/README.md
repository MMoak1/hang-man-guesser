This is a hang_man simulator, what this is supposed to do the user thinks of a word
and the program tries to guess it. it does this by performing anylisis on the words.txt files. 


The program will ask the user for a letter, and if the letter is in the word, it will display the word with the letter filled in. If the letter is not in the word, it will display a message saying that the letter is not in the word. The program will continue to ask for letters until it either guesses the word or runs out of guesses.
